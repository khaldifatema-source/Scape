# 🔒 الهروب من مختبر الذكاء الاصطناعي (AI Lab Escape Room)

نشاط تقويم ختامي تفاعلي وتطبيقي لمادة **التقنية الرقمية** (المرحلة الثانوية - المملكة العربية السعودية) حول موضوع **الذكاء الاصطناعي ومراحل تعلم الآلة وتطبيقاتها الواقعية**.

---

## 🎯 فكرة النشاط
تعيش الطالبة تجربة لعبة هروب رقمية داخل مختبر ذكاء اصطناعي مستقبلي فُرض عليه إغلاق أمني تلقائي. لا يمكن فتح الأبواب إلا بعد اجتياز 4 تحديات تعليمية متتابعة:
1. **القفل الأول (سر البيانات):** جودة البيانات وتمثيلها للمهمة المطلوبة.
2. **القفل الثاني (شفرة الآلة):** ترتيب مراحل تعلم الآلة الأربعة (جمع البيانات ➔ معالجة البيانات وتجهيزها ➔ تدريب النموذج ➔ تقييم النموذج).
3. **القفل الثالث (اختبار الذكاء):** تقييم النموذج باستخدام بيانات اختبار مستقلة والتعميم على البيانات غير المرئية.
4. **القفل الرابع (تطبيقات تعلم الآلة):** تطبيقات تعلم الآلة المعتمدة في كتاب التقنية الرقمية (التعرف على الصور كالنظارات الذكية للمكفوفين، التعرف على الكلام، الترجمة الآلية، والتعلم المخصص).

---

## 🚀 طريقة النشر والتفعيل على GitHub Pages مجانًا

تم تجهيز المشروع بالكامل ليعمل مباشرة وبشكل تلقائي فور رفعه على GitHub عبر **GitHub Actions**.

### خطوات التفعيل بنقرات بسيطة:

1. **إنشاء مستودع (Repository) على GitHub:**
   * أنشئي مستودعًا جديدًا (Public) على حسابك في GitHub.
   * قومي بدفع (Push) أو نشر هذا المشروع إليه مباشرة من واجهة AI Studio.

2. **تفعيل GitHub Pages في المستودع:**
   * في صفحة المستودع على GitHub، اضغطي على تبويب **Settings** (الإعدادات).
   * من القائمة الجانبية اليسرى، اختاري **Pages**.
   * تحت قسم **Build and deployment** ستجدين خيار **Source**:
     * غيّريه من `Deploy from a branch` إلى:
     * 👉 **`GitHub Actions`**
   * سيعمل ملف الـ Workflow المرفق تلقائيًا (`.github/workflows/deploy.yml`)، ويبني الموقع وينشره في غضون ثوانٍ.

3. **الحصول على الرابط:**
   * بعد دقيقة واحدة، ستجدين رابط موقعكِ المنشور جاهزًا في أعلى صفحة Pages، على هذا النمط:
     `https://<your-username>.github.io/<repository-name>/`
   * يمكنكِ إرسال الرابط مباشرة للطالبات أو فتحه على جهاز الآيباد أو شاشة العرض الذكية في الفصل.

## 💻 التشغيل المحلي والتطوير

إذا أردتِ تشغيل المشروع على جهازكِ الشخصي:

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build
```

## ✨ المميزات التعليمية

* متوافق بالكامل مع أجهزة **iPad** والجوالات والحواسب (أزرار لمس كبيرة وواضحة).
* مؤثرات صوتية رقمية هادئة تم توليدها تقنيًا بدون ضوضاء مزعجة في الفصل (مع زر كتم الصوت).
* **لوحة تحكم وتخصيص للمعلمة** تتيح تعديل نصوص الأسئلة والمراحل وتوقيت المؤقت.
* **شهادة إنجاز رقمية قابلة للطباعة** باسم الطالبة أو المجموعة لعرضها أمام المشرفة الزائرة والمعلمات.
* لا يتطلب تسجيل دخول أو جمع أي بيانات شخصية.
